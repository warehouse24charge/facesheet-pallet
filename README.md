# facesheet-pallet

เว็บแอปพลิเคชันสำหรับสร้างและพิมพ์ใบปะหน้าพาเลท / ใบปะหน้าสินค้า 8 ช่อง บนกระดาษขนาด A4

## คุณสมบัติเด่น
- จัดหน้าแบบ 8 ช่องพอดีกระดาษ A4
- ปรับแต่งข้อความ, สีแถบหัว, ขนาดตัวอักษร, เส้นประสำหรับตัดได้แบบ Real-time
- รองรับโหมดแก้ไขช่องเดียวแล้วอัปเดตทุกช่องพร้อมกัน (Sync)
- ออกแบบสำหรับพิมพ์ (Print to PDF / Print) ด้วยสัดส่วนคมชัด 100% (A4)
